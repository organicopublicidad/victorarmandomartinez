# victorarmandomartinez.com

Hoja de vida web de Víctor Armando Martínez Perafán, hecha con [Astro](https://astro.build).

- **Textos:** `src/data/contenido.ts`
- **Fotos:** `src/assets/fotos/<nombre>.jpg` (se ubican solas por nombre)
- **Videos propios:** `src/assets/videos/<nombre>.mp4` (si faltan, se usa el enlace de YouTube de `contenido.ts`)
- **Publicación:** cada `git push` a `main` publica automáticamente en GitHub Pages.

```bash
npm install
npm run dev
```
